## 二、架构约束（H2 定稿，必须逐条执行）

### M1：`extern-api/server/routes/openapiRoutes.js` — 新增 /docs/ui 路由

在文件末尾 `export default router` 之前、`/openapi.yaml` 路由之后新增：

```js
import { fileURLToPath } from 'url'
import { dirname, join } from 'path'
// （放文件顶部 import 区）
const __dirname = dirname(fileURLToPath(import.meta.url))

router.get('/docs/ui', (req, res) => {
  res.set('Cache-Control', 'no-cache')
  res.set('X-Content-Type-Options', 'nosniff')
  try {
    const htmlPath = join(__dirname, '..', 'views', 'swagger-ui.html')
    res.sendFile(htmlPath)
  } catch (err) {
    res.status(500).type('text/plain').send('swagger-ui.html not found')
  }
})
```

**注意**：`__dirname` 推导只需一份（放 import 区）；`res.sendFile` 路径必须指向新建的 views 文件；挂载后最终 URL = `GET /api/docs/ui`（路由挂载于 /api 前缀，自动继承 apiLimiter）。

### M2：**新建** `extern-api/server/views/swagger-ui.html`（~130 行，纯静态，无外部依赖）

**要求**：
- `<meta charset="utf-8">`；标题 `MechAssist API`；说明行「从 GET /api/openapi.json 自动生成」
- `<style>`：body 居中 max-width 900px；`.group h2` 下边框；方法徽章 `.badge.get/post/put/delete/patch/other`（GET #49cc90、POST #61affe、PUT #fca130、DELETE #f93e3e、PATCH #9b59b6、其他 #999，白字）；路径 monospace；摘要灰色
- `<script>`（inline，利用 CSP 已含 unsafe-inline）：
  - `fetch('/api/openapi.json')` → 非 200 或 catch → 显示 `#error` 块：「⚠ 加载失败：无法获取 OpenAPI 规范。请确认 extern-api 已启动（:3002）。」
  - 分组：遍历 `spec.paths`，取路径第二段（`/api/<group>/...`，无 /api 前缀的如 `/health`、`/v2/` 归入 `other`）作为 key
  - 分组显示名映射（7 组）：`auth→认证`、`chat→对话`、`faq→FAQ`、`repair-records→维修记录`、`admin→管理`、`release→发布`、`other→系统`（其他未列出的段按原样显示）
  - 每组渲染表格行：方法徽章 + 路径 + summary（`o.summary || '—'`）；按方法顺序 GET<POST<PUT<PATCH<DELETE 排序
  - 所有渲染值用 `escapeHtml` 或 textContent 方式防注入（spec 内容理论上可信，但保持防御）
- 页面不得包含任何密钥/Token/URL 值；无外部 CDN 引用
