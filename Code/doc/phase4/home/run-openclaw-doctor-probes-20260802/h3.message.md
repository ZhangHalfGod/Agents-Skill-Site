**2) 文件末尾（"Cursor code (V5):" 提示段之后）追加 probe 汇总段**，结构如下（核心逻辑精确按此，中文注释保留 UTF-8）：

```powershell
# --- probe summary (per profile) ---
if ($Profile) {
  $root = Join-Path $PSScriptRoot "..\.."          # scripts/openclaw/
  $profilePath = Join-Path $root "profiles\$Profile\profile.json"
  if (-not (Test-Path -LiteralPath $profilePath)) {
    Write-Host "WARN: profile.json not found: $profilePath" -ForegroundColor Yellow
    exit 0
  }
  $meta = Get-Content -LiteralPath $profilePath -Raw -Encoding UTF8 | ConvertFrom-Json
  Write-Host ""
  Write-Host "=== probe summary (profile: $Profile) ===" -ForegroundColor Cyan

  $results = @()   # @{ label; status; detail }
  $totalFail = 0

  # weather
  if ($meta.capabilities -contains "weather") {
    $out = & (Join-Path $root "common\weather\probe-weather.ps1") 2>&1 | Out-String
    $code = $LASTEXITCODE
    if ($code -eq 0) { $results += [pscustomobject]@{ label="weather"; status="PASS"; detail=($meta.weatherBackend + ": " + ($out -split "`r?`n" | Where-Object { $_ -match "^\S.*\d+°" } | Select-Object -First 1)) } }
    else { $results += [pscustomobject]@{ label="weather"; status="FAIL"; detail=($out -split "`r?`n" | Select-Object -First 1) }; $totalFail++ }
  }

  # tts
  if ($meta.capabilities -contains "tts") {
    $out = & (Join-Path $root "common\tts\probe-tts.ps1") 2>&1 | Out-String
    $code = $LASTEXITCODE
    if ($code -eq 0) { $results += [pscustomobject]@{ label="tts"; status="PASS"; detail=($meta.ttsEngine + " :9880") } }
    else { $results += [pscustomobject]@{ label="tts"; status="FAIL"; detail=($out -split "`r?`n" | Select-Object -First 1) }; $totalFail++ }
  }

  # routing（恒 exit 0 → 双维度判定）
  if ($meta.capabilities -contains "routing") {
    $out = & (Join-Path $root "common\routing\probe-routing.ps1") 2>&1 | Out-String
    $code = $LASTEXITCODE
    if ($code -ne 0) { $results += [pscustomobject]@{ label="routing"; status="FAIL"; detail=($out -split "`r?`n" | Select-Object -First 1) }; $totalFail++ }
    elseif ($out -match "节点离线|exit=2") { $results += [pscustomobject]@{ label="routing"; status="WARN"; detail="mac node offline (expected)" } }
    else { $results += [pscustomobject]@{ label="routing"; status="PASS"; detail="route ok" } }
  }

  foreach ($r in $results) {
    $color = if ($r.status -eq "PASS") { "Green" } elseif ($r.status -eq "WARN") { "Yellow" } else { "Red" }
    Write-Host ("{0,-10} {1,-6} {2}" -f $r.label, $r.status, $r.detail) -ForegroundColor $color
  }
  $passCount = ($results | Where-Object status -eq "PASS").Count
  $warnCount = ($results | Where-Object status -eq "WARN").Count
  Write-Host ("Result: {0} PASS, {1} WARN, {2} FAIL" -f $passCount, $warnCount, $totalFail)
  if ($totalFail -gt 0) { exit 1 }
}
```

**实现要求**：
- 相对路径用 `$PSScriptRoot` 推导（doctor 在 common/install/ → 上两级到 scripts/openclaw/），禁止硬编码绝对路径
- `$LASTEXITCODE` 必须在每次调用后立即捕获（PowerShell 特性）
- 分项表三行 weather/tts/routing 必须输出（profile capabilities 含三者时）；状态着色 Green/Yellow/Red
- 任一 FAIL → `exit 1`；WARN 不计；全部 PASS/WARN → exit 0（无显式 exit 即自然退出 0）
- 无 `-Profile` 参数 → 整个 probe 段不执行，保持旧行为
