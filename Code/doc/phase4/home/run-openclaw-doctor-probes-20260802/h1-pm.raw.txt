## 2. 范围条目

### 2.1 原位探查结论

#### doctor.ps1 现状

- 执行：`openclaw --version` → `openclaw doctor` → `openclaw gateway status` → 打印提示
- **不调用任何 probe 脚本**，**无 PASS/WARN/FAIL 输出**，退出码取决于 openclaw CLI

#### 三个 probe 脚本契约

| 脚本 | 依赖 | 退出码 | 备注 |
|------|------|--------|------|
| `weather/probe-weather.ps1` | wttr.in HTTPS | 0=OK, 1=FAIL | 有 `-City`/`-TimeoutSec` 参数 |
| `tts/probe-tts.ps1` | :9880 HTTP | 0=OK, 1=FAIL | 有 `-BaseUrl`/`-Text`/`-ApiKey` |
| `routing/probe-routing.ps1` | Test-OpenClawRoute + invoke-route | **恒 0** | Mac 离线也 exit 0——需解析输出判定 |

#### Profile 结构（bm/home 的 profile.json）

| Profile | weatherBackend | ttsEngine | capabilities |
|---------|---------------|-----------|-------------|
| bm | wttr.in | system-speech | weather,tts,routing,coding,model-switch |
| home | mcp-gaode | cosyvoice | 同上 |

`apply-profile.ps1` 按 `capabilities` 数组决定启用哪些能力，doctor 复用此逻辑。

#### Doctor 调用方——安全无破坏

| 位置 | 引用方式 | 影响 |
|------|---------|------|
| `install-windows.ps1` L28 | 提示"Optional: openclaw doctor" | 无 |
| `README.md` L14 | 目录标注 | 无 |
| `docs/README.md` L3 | 描述 doctor 功能 | P2 更新 |

无程序化调用 doctor，改动安全。

### 2.2 修改条目（P0）

| # | 文件 | 修改动作 |
|---|------|---------|
| M1 | `doctor.ps1` | 新增 `-Profile` 参数（`[ValidateSet("bm","home")]`）；保留前段；末尾新增 probe 汇总段：读取 profile.json → 调 weather/tts/routing probe → 捕获退出码 → 输出 PASS/WARN/FAIL 表 → 任一 FAIL 则 exit 1 |
| M2 | 同上 | PASS/WARN/FAIL 判定：probe exit 0 → PASS；exit ≠ 0 → FAIL；routing probe 恒 0 → 解析输出含"离线"→ WARN |

