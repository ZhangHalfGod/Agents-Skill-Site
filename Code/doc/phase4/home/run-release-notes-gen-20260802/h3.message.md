## 二、架构约束（H2 定稿，必须逐条执行）

### M1：**新增** `scripts/release-notes-gen.mjs`（ESM，~120 行，对齐 `scripts/release-triplet-check.mjs` 风格）

**功能**：fetch manifest → 解析 → 生成 7 节 Markdown → writeFile → exit 0/1。

**环境变量与默认值**：
- `EXTERN_API_URL`：默认 `http://127.0.0.1:3002`（自动去尾斜杠）
- `RELEASE_OUTPUT_DIR`：默认 `doc/方案C/方案C_MVP_M1-M4_对接/M-4_版本契约与发布联动/`（用 `fs.mkdirSync({recursive:true})` 自动创建）
- `RELEASE_PROBE`：默认 `false`（`!== 'true'` 视为 false）→ 请求 `?probe=false`；仅当 `=== 'true'` 才 `?probe=true`
- CLI 参数 `--output=<path>` 覆盖输出路径；默认输出名 `发布清单-YYYYMMDD.md`（本地日期）

**请求**：`fetch(${base}/api/release/manifest?probe=false)`；HTTP 非 200 或 JSON 解析失败或 `data` 为 null → 打印中文错误 → exit 1。

**7 节 Markdown 输出**（每节标注 `(auto)` / `(fixed)` / `(placeholder)`）：

1. `# 方案 C 发布清单 — YYYY-MM-DD（自动生成）` + 说明行 `> 由 scripts/release-notes-gen.mjs 从 GET /api/release/manifest 生成。`
2. `## 一、元信息 (auto)`：deployEnv、buildTime、gitSha、serviceVersion 自动填充；发布日期/操作人/关联需求留空（placeholder 标注）
3. `## 二、发布三元组 (auto)`：**6 行表**（列：组件 | 版本标识 | Git commit）：
   - extern-api · Prompt | `d.releaseTriplet.promptVersion` | `d.releaseTriplet.commit`
   - extern-api · 注册表 | `d.releaseTriplet.registryVersion` | —
   - extern-api · 服务 | `d.serviceVersion` | `d.gitSha`
   - mcp-gaode · capabilities | `d.mcp?.capabilitiesVersion ?? '—'` | —
   - mcp-faq · capabilities | `d.mcpMech?.capabilitiesVersion ?? '—'` | —
   - extern · deployEnv | `d.deployEnv` | —
4. `## 三、发布前检查 (placeholder)`：固定清单文本（npm test / manifest 验证 / capabilities 检查），待人工勾选
5. `## 四、部署顺序 (fixed)`：5 步固定建议文本（参考 发布清单-模板.md §四）
6. `## 五、回滚 (fixed)`：4 步固定回滚文本（参考 发布清单-模板.md §五）
7. `## 六、发布后验证链接 (auto/placeholder)`：auto 行 `/health`、`/api/release/manifest`、`/capabilities`（基于 EXTERN_API_URL 推导）；前端地址留空
8. `## 七、备注 (placeholder)`：留空

**无密钥硬约束（禁止出现在输出或 stdout）**：`MCP_*_BASE_URL`、`API_KEY`、`TOKEN`、`SECRET`、`password`、`Bearer`、任何完整 URL 值；`console.log` 仅允许输出 `Wrote: <path>` 和错误信息。probe=true 时 mcp 段仍只打印 `compatible/reachable/configured/capabilitiesVersion`，**不打印 baseUrl**。

**字段缺失**：一律用 `?.` + `?? '—'`，缺失写 `—` 不崩溃、不 exit 非零。

**退出码**：成功 0；网络/HTTP/解析/写入失败 1。
