### M1a：`extern-api/server/services/mcpToolUserMessages.js` — stripErr 增加 error.code 脱敏

当前 `stripErr`（约 L103-L112）：
```js
const stripErr = (err) => {
  if (!err || typeof err !== 'object') return err
  const msg = err.message != null ? String(err.message) : ''
  const safeMsg = buildUserVisibleFailureLine({
    phase: 'tool_business', globalToolName, rawMessage: msg
  })
  return { ...err, message: safeMsg }
}
```
改为（在 return 前插入）：
```js
  const safe = { ...err, message: safeMsg }
  // 脱敏：删除内部 error.code，防止 LLM 复述到用户可见回复
  if (safe.code != null && isUnsafeForUserDisplay(safe.code)) {
    delete safe.code
  }
  return safe
```
语义：code 为 null/undefined → 保留；不匹配 LEAK_PATTERNS → 保留；匹配 → 删除（不替换）。top-level 与 nested result.error.code 两条路径共用 stripErr，一处修改全覆盖（无需改 sanitizeEnvelopeForLlm 主体）。

### M1b：同文件 — LEAK_PATTERNS 扩展

  /^QUOTA_[A-Z0-9_]+\b/i,      // 新增：配额错误码
  /^MCP_[A-Z0-9_]+\b/i,        // 新增：MCP 协议错误码
