# 架构约束与接口_Web-UI.md — 交付摘要

## 核心决策

| 决策 | 结论 |
|------|------|
| **Monorepo** | 采用 `web/apps` + `web/packages`（api-client / domain / ui-kit），P2 ar-shell 零重构 |
| **四层架构** | Presentation → Application → Domain ← Infrastructure；Infrastructure 唯一持有 `VITE_API_BASE` |
| **技术栈** | Vue3 + Vite + TS + Pinia（可选）；零 UI 组件库；fetch + AbortController |
| **/v2 发现驱动路由** | 首次加载 GET /v2，links[] 缓存，无硬编码端点 URL |
| **CORS** | 开发 Vite proxy 足够；RK3588 同源；Jetson 后端加 `*` |
| **Mock 策略** | api-client 内置 interceptor + `_meta.isMock` 字段驱动 MockBadge |
| **WS stub** | `IStatusRepository` 接口 → P0 MockStatusRepository → P1 WsStatusRepository |
| **红色记录** | 不触发——纯前端普通模块 |
