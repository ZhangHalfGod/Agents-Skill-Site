# AI代码生成范围清单

> **项目**: MechAssist-Fusion / extern-api  
> **阶段**: H1（需求拆解）  
> **原始需求**: 发现面挂载 OpenAPI + Voice 进 registry（契约对齐）  
> **产出日期**: 2026-07-31  
> **优先级约定**: P0 = 验收口径直接命中 / P1 = 质量增强（测试/快照/标注） / P2 = 可选体验优化

---

## 1. 目标

使 `GET /api/docs` 与 `GET /v2` 的发现面完整反映当前已实现的 API 能力：

- **目标 A — OpenAPI 挂发现面**：`/api/docs` 和 `/v2` 中增加 OpenAPI 契约入口（`/api/openapi.json`、`/api/openapi.yaml`），使 API 消费者仅通过浏览发现面即可定位契约文件。
- **目标 B — Voice 进 registry + 修正过时标注**：三条已落地的 voice 路由（`GET /api/voice/capabilities`、`POST /api/voice/tts`、`GET /api/voice/tts/files/:fileName`）以 `implemented: true` 写入 `LAYERS`，并修正 `PATH_FALLBACKS` 中「尚未实现 Express handler」的错误 xNote，使 `/api/docs` 与 `/api/openapi.json` 均反映真实状态。
- **目标 C — 存量不破**：不引入新的测试失败，不改动热路径，不改业务逻辑。

## 3. 显式不做

1. **不做 OpenAPI 生成器重构**：不改 `generateOpenApiSpec()` 的算法、不新增 `parseParamMeta()` 的解析能力、不新增 operation 字段类型。
2. **不做 Swagger UI 前端集成**：仅暴露 JSON/YAML 文件路径供外部工具消费，不嵌入 Swagger UI 页面。
3. **不做 voice 服务的认证模式变更**：voice 端点按 `chatRoutes.js` 现状保持 `authenticateToken`（auth: true），不改为公开。
4. **不做全量 PATH_FALLBACKS 审计**：仅修正 voice 三条，GATEWAY_PLANES / GATEWAY_CONTROL_PLANE / GATEWAY_DATA_PLANE 的 fallback 暂不动（与本次需求无关）。
5. **不做 `/api/docs` 的 JSON Schema 版本升级**：`getApiDocsPayload()` 保持现有结构，仅插入 `openapi` 字段。

## 6. 风险与回滚

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| A1 后 `PATH_FALLBACKS` 与 `LAYERS` 双源导致 `/api/openapi.json` 中 voice 端点重复 | 低 | `/api/openapi.json` 同一路径下出现重复 method → OpenAPI 校验警告 | `collectLayerEndpoints()` 命中 LAYERS 后 `continue`，不会走到 fallback 分支；已通过代码阅读确认该控制流。若出现意外重复，移除 `PATH_FALLBACKS` 中 voice 三键即可（M4 可选做）。 |
| 快照更新误引入无关 Diff | 中 | 快照测试假阳性失败，阻塞 CI | 仅允许变更与 voice / openapi 相关的 diff；快照更新前 `diff` 确认变更范围。 |
| A2 顶层字段 `openapi` 被现有前端代码消费时不受影响 | 极低 | 前端消费 `/api/docs` 时忽略未知字段 | `/api/docs` 返回 `{ success: true, data: getApiDocsPayload() }`；`openapi` 在 `data` 内部，前端按需取用，不破坏现有结构。 |
| auth 属性与 PATH_FALLBACKS 不一致 | 低 | A1 设 `auth: true`，但 PATH_FALLBACKS 原设 `auth: false` | `collectLayerEndpoints()` 从 LAYERS 取值，fallback 不再生效；以 LAYERS 为真源即可。 |
| 回滚 | — | `git checkout -- server/catalog/registry.js server/catalog/openapiGenerator.js server/test/openapi.test.js`；还原快照文件 | |
