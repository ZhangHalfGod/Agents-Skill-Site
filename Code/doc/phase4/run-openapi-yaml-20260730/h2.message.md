### H1 Decisions（不可推翻）

1. YAML 序列化使用 js-yaml（已存于 node_modules 的传递依赖），不引入新 npm 包、不跑 npm install
2. 不修改 openapiGenerator.js——generateOpenApiSpec() 对 JSON/YAML 返回相同 JS 对象，序列化差异在路由层处理
3. 不修改 server/index.js——YAML 路由挂在已有 openapiRoutes 的同一个 Express Router 上，index.js 无需感知
4. Content-Type 使用 application/yaml（非 text/yaml），与 OpenAPI 生态一致
5. YAML 语义等价通过反向解析（yaml.load()→JS对象）验证关键字段，不引入 YAML 快照文件
6. 本次改动为普通模块（路由扩展），不触发核心模块红色记录
